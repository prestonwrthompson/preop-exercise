Do not make triage decisions. Do not return READY, NEEDS_FOLLOW_UP, or NOT_CLEARED.
Return only the requested JSON facts.

Your job is to identify and extract:

1. History and Physical (H&P) documents
   - For each document that is or appears to be an H&P, return its documents[] index and best available date (YYYY-MM-DD).

2. Surgical consent documents
   - For each document that is or appears to be surgical consent, return its index, date if available, and whether the text clearly indicates signed consent.

3. Perioperative anticoagulation plan documents
   - For any document that discusses perioperative anticoagulation management, return its index and whether the plan is clear (specific hold/resume timing or bridging instructions).

4. Medications
   - For each medication, indicate whether it is an anticoagulant based on the medication name and chart context.

Use the submission JSON indexes exactly:
- documents[0] is document_index 0
- medications[1] is medication_index 1

If a fact cannot be determined, use null.
If none exist for a category, return an empty array for that section.

Do not invent documents or medications that are not in the submission.

Example output shape:

    {"document_index": 0, "date": "2026-02-21"}
  ],
  "surgical_consent_documents": [
    {"document_index": 2, "date": "2026-02-25", "is_signed": true}
